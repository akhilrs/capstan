A controller for your AI coding agents.

Describe the work to one PM agent. It spawns developers, reviewers and testers as real Claude Code or Codex sessions, each in its own pane, worktree and branch, and tells you which branch to merge.

$ curl -fsSL https://raw.githubusercontent.com/akhilrs/capstan/main/install.sh | sh

Linux x64 and arm64. No sudo: static cstan and cstan-dash binaries in ~/.local/share/capstan, linked from ~/.local/bin. Read install.sh

How a task moves

Nothing is guessed from terminal text. Every step is a fact in a SQLite ledger.

  1. You ask the PMIt picks a tier. Small work goes straight to a developer; larger work goes to an Architect, who splits it into packages.
  2. Workers buildEach commits on its own branch, never pushes or merges, and runs cstan report with a full commit id. The controller checks the commit is on that branch before the PM hears about it.
  3. Reviews are independentA fresh reviewer starts at the reported commit and answers once. Findings go back to the developer, who amends and reports again.
  4. Integration is mechanicalReviewed reports are squashed onto an integration/<id> branch without touching your checkout. A conflict becomes a new task.
  5. You mergeThen cstan integrate confirm tells the controller to clean up.

First run

# in the repository you want the team to work on
$ cstan init
$ cstan config check
$ cstan start
$ cstan dash   # optional

You need Linux (x64 or arm64), git with a repository that has at least one commit, Herdr for the panes and Claude Code for the PM.

Then switch to the PM's Herdr pane and say what you want built. cstan stop shuts the controller down.

Install options

Re-running the installer upgrades in place. It checks both binaries against the release's SHA256SUMS. Only Linux x64 and arm64 are published; macOS is not supported.

Coming from 0.3 or earlier, the Node.js releases? Remove any global npm install, then run the installer. Upgrading from 0.3

Install reference

# pin a release (0.4.0 or newer)
$ curl -fsSL https://raw.githubusercontent.com/akhilrs/capstan/main/install.sh \
    | sh -s -- --version 0.4.1
# skip the dashboard
$ curl -fsSL https://raw.githubusercontent.com/akhilrs/capstan/main/install.sh \
    | sh -s -- --no-dash
# remove the install and the cstan link
$ curl -fsSL https://raw.githubusercontent.com/akhilrs/capstan/main/install.sh \
    | sh -s -- --uninstall

Rust 0.4 against Node 0.3

Since 0.4.0 Capstan is a Rust program. We measured the published 0.3.0 and 0.4.0 binaries side by side on one shared, busy VM, so treat the figures as rough.

MeasureNode 0.3.0Rust 0.4.0Change
Download131.7 MB10.0 MB13 times smaller
One CLI call182 to 185 ms6 to 7 ms27 to 30 times faster
Memory per CLI call68 to 70 MB1.3 to 2.5 MBabout 97% less
Idle daemon memory73.2 MB7.5 MB90% less
Daemon start404 ms114 ms3.5 times faster
medians of 3 interleaved rounds, Linux x64
