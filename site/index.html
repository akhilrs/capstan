A controller for your AI coding agents.

Describe the work to one PM agent. It spawns developers, reviewers and testers as real Claude Code or Codex sessions, each in its own pane, worktree and branch, and tells you which branch to merge.

$ curl -fsSL https://raw.githubusercontent.com/akhilrs/capstan/main/install.sh | sh

No sudo. Linux x64 and arm64 get a standalone binary; elsewhere it needs Node 24.6 or newer. Read install.sh

How a task moves

Nothing is guessed from terminal text. Every step is a fact in a SQLite ledger.

  1. You ask the PMIt picks a tier. Small work goes straight to a developer; larger work goes to an Architect, who splits it into packages.
  2. Workers buildEach commits on its own branch, never pushes or merges, and runs cstan report with a full commit id. The controller checks the commit is on that branch before the PM hears about it.
  3. Reviews are independentA fresh reviewer starts at the reported commit and answers once. Findings go back to the developer, who amends and reports again.
  4. Integration is mechanicalReviewed reports are squashed onto capstan/integration/<id> without touching your checkout. A conflict becomes a new task.
  5. You mergeThen cstan integrate confirm tells the controller to clean up.

First run

# in the repository you want the team to work on
$ cstan init
$ cstan config check
$ cstan start
$ cstan dash   # optional

You need git, Herdr for the panes and Claude Code for the PM.

Then switch to the PM's Herdr pane and say what you want built. cstan stop shuts the controller down.
