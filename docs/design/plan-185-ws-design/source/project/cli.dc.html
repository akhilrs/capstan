02 cstan text: status, plan show --brief, verify and cleanup

A set is one line: set <set id> <branch>, the strip in merge order, then the summary. A second, dim line names only the members that need a word: the next repo, the review subject, a conflicted or failed member with its attempt, and dropped members. Nothing else is listed, so the line count does not grow with the repo count. Colour comes from the dash roles; under NO_COLOR the words and glyphs carry everything (right column).
