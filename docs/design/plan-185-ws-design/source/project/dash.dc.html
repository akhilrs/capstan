03 cstan dash: the pipeline and agents panels

A set is one pipeline row. The STATE column holds the strip (10 cells: up to 10 glyphs, else 7 and "+n"); WHO / COMMIT holds the set id and a short summary. The members' own integration items fold into the set row. Selecting a set fills the selected area with its members in merge order: the next repo carries the row marker and "next", the review subject "review", a dropped member is dim with "outside the gate". The stage line counts a set once, with the set words. Frames are drawn by a script at the exact panel width (60 cells in the 120-column layout, 80 in the one-column layout).

Empty: a workspace project with no set shows the existing "no integrations" line. Loading and error: the existing link states (● answering / ○ link down) and the last frame stay. Hover does not exist in the terminal; focus is the heavy border of the focused panel and the ▌ row marker, as today.
