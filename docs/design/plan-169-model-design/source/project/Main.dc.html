Which model an agent runs, and where that came from

The host sends model and modelSource for each agent. The id is untrusted text: shown in mono, as plain text, never a link. The source is never shown as sent: it maps to one of the labels below, and any value the app does not know reads “other”.

modelSourceIn a list rowIn the inspector and detailVoiceOver saysMeans
spawnspawnChosen at spawn“chosen at spawn”cstan spawn --model
tasktaskTask override“task override”an override on the agent’s task
planplanPlan override“plan override”an override on the agent’s plan
roleroleRole setting“role setting”the role’s model in capstan.toml
hosthostHost setting“host setting”the host’s model in capstan.toml
defaultsdefaultsConfig defaults“config defaults”[defaults] in capstan.toml
anything else, or absentotherOther source“other source”a source this app version does not know

A long id (100 bytes, the most the host stores)

Rows cut it in the middle, so the family and the version suffix stay:

claude-sonnet-5-5-2026…9c2e1b4d[1m] · spawn

The inspector and detail show it whole, wrapped at any character:

claude-sonnet-5-5-20261015-long-context-preview-eu-west-batch-build-7f3a9c2e1b4d-0a1b2c39c2e1b4d[1m]

Nothing to show

No model (an older host, an agent started before the change, or a role with no model): nothing is shown. No dash, no “unknown”, no row in the inspector, no words for VoiceOver.

A source with no model: nothing. A model with no source: the id with “other”.

An id that is empty after the app cleans it (control characters removed, one line): treated as no model.
