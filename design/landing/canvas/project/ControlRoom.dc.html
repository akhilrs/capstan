A controller for your AI coding agents.

Describe the work to one PM agent. It spawns developers, reviewers and testers as real Claude Code or Codex sessions, each in its own pane, worktree and branch, and tells you which branch to merge.

$ curl -fsSL https://raw.githubusercontent.com/akhilrs/capstan/main/install.sh | sh

{{copyStatus}}

No sudo · standalone binary on Linux x64/arm64 · otherwise Node 24.6+ · read install.sh

Nothing is guessed from terminal text.

  1. 01Delivered, acknowledged mailOne queue per agent. A message waits while a worker is busy and stays blocked until acknowledged.
  2. 02Verified reportsA report names a full commit id; the controller checks it lies on that worker's branch first.
  3. 03Independent reviewsEach review is a fresh Verifier at the reported commit. It answers once and is ended.
  4. 04You hold the mergeReviewed work is squashed onto capstan/integration/<id>. Your checkout is never touched.

First run

# in the repo you want the team to work on
$ cstan init
$ cstan config check
$ cstan start
$ cstan dash   # optional

Then switch to the PM's Herdr pane and say what you want built.

cstan stop shuts the controller down.
