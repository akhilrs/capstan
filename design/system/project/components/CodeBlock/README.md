# Code block

A block of shell commands on `surface`, with an amber prompt and muted comments.

- Markup: `pre.cap-code`; wrap each `$ ` in `span.cap-code__prompt` (not selectable) and each `# comment` in `span.cap-code__comment`.
- Lines wrap instead of scrolling, so long commands stay readable on phones.
- For inline commands in prose use `code.cap-inline`.
- The install command does not go here; it has the Install bar.
